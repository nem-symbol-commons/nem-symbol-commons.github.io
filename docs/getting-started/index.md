NEM & Symbol Commons は、NEM（NIS1）と Symbol の開発・運用に役立つ知識を共有する、日本語のドキュメントサイトです。
アプリケーション開発やノード運用に取り組む方に向けて、API・SDK の使い方、構築手順、公式仕様や実装へのリンクをまとめています。

## はじめての方へ

NEM と Symbol について知るには、[両チェーンの違い](../common/nem-and-symbol.md)と[基本用語](glossary.md)から読み始めてください。

開発を試す方は、[Symbol](../symbol/quickstart.md)または [NEM](../nem/quickstart.md) のクイックスタートへ進んでください。
送信を試す際は、Testnet 用の専用アカウントを使います。

- [開発者向けリンク集](../references/developer-links.md)：公式資料、GitHub、SDK、Explorer。
- [ネットワーク情報一覧](../references/networks.md)：接続先、ネットワーク識別子、主要ポート。
- [REST APIの基本](../references/rest-api.md)：API の呼び出し方、レスポンス、エラーの扱い。

## 記事の読み方

NEM（NIS1）と Symbol は別のチェーンです。記事やコード例を使う前に、対象チェーン・ネットワーク・バージョンを確認してください。
Testnet の再構築や API の更新後は、リンク先の仕様や実装も確認してください。

リンクの ↗ は外部サイトを示します。

## 記事の改善に参加する

誤字、リンク切れ、古いコード例は [Issue](https://github.com/nem-symbol-commons/nem-symbol-commons.github.io/issues) で報告してください。
不具合の報告には対象ページ、利用したバージョン、再現条件を添えます。秘密鍵や認証情報は含めないでください。

記事の修正・追加は[コントリビューションガイド](https://github.com/nem-symbol-commons/nem-symbol-commons.github.io/blob/main/CONTRIBUTING.md)を参照してください。
