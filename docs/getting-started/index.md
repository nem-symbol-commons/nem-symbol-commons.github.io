NEM & Symbol Commons は、NEM / Symbol の開発と運用に関する知識を日本語で共有するサイトです。
現在はカテゴリと参照資料の入口を整備しており、具体的な解説記事は順次追加していきます。

## どこから読むか

- 対象チェーンの仕様や開発を調べる: [Symbol](../symbol/index.md) / [NEM（NIS1）](../nem/index.md)
- 技術の共通点や違いを調べる: [共通技術・比較](../common/index.md)
- ノードを構築・保守する: [ノード運用](../node-operation/index.md)
- 通信やデータ形式を調べる: [プロトコル](../protocol/index.md)
- 鍵の取り扱いを確認する: [セキュリティ](../security/index.md)
- 問題から対処方法を探す: [トラブルシューティング](../troubleshooting/index.md)
- API・SDK や一次資料を探す: [リファレンス](../references/index.md)

## 読み進める前に

記事の対象が NEM（NIS1）と Symbol のどちらか、利用するソフトウェアのバージョン、対象ネットワークを確認してください。
同じ名前の機能でも、仕様や操作方法をそのまま流用できるとは限りません。
基本用語や情報源の読み方も、このカテゴリで整備していきます。
