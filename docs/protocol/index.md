P2P 通信、バイナリ形式、ファイナライズなど、プロトコルと実装に関する情報を扱うカテゴリです。
テーマごとに対象チェーンを明記し、仕様書やソースコードを根拠に整理していきます。

## 実装を調べるとき

調査対象のリリースやコミットを特定し、メッセージ形式、フィールドのサイズ、バイトオーダーなどを確認します。
片方のチェーンで確認した仕様を、もう片方にも適用できるものとして扱わないでください。

ソースコードの入口は [リファレンス](../references/index.md)、暗号技術の基礎や比較は [共通技術・比較](../common/index.md) を参照してください。
