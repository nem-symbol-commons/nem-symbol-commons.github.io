NEM（NIS1）固有の仕様と開発を扱うカテゴリです。
アカウント、トランザクション、モザイク、ネームスペースなどのテーマを、Symbol の仕様と区別して整理していきます。

## 調べるための入口

- [NEM のソースコード](https://github.com/NemProject/nem): 実装や変更履歴を確認する。
- [リファレンス](../references/index.md): 対象チェーンに対応する API・SDK の資料を探す。
- [共通技術・比較](../common/index.md): NEM と Symbol の違いを整理する。

資料やコード例を利用する前に、NEM（NIS1）を対象としていることと、対応バージョンを確認してください。

## 最初に試す

[NEM開発クイックスタート](quickstart.md)で、NIS1 Testnet の情報取得と XEM 転送のローカル署名を試せます。
対象は `symbol-sdk@3.3.3` の NEM API です。Symbol の送信 API とは異なります。

## イベント通知

[NEM WebSocket](websocket.mdx)で、NIS1 の SockJS / STOMP 接続と購読パスを確認できます。
ノードの構築記事は [ノード運用](../node-operation/nem/setup.mdx) に配置しています。
