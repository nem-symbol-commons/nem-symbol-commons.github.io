NEM(NIS1)ノードを Ubuntu 26.04 LTS（amd64）でビルドします。
ビルド済みノードが公開されていない場合や、自分でビルドしたい場合に役立ちます。
配布済みの NIS1 をコンテナーで動かす場合は、[Docker イメージの作成と起動](./docker.mdx)を参照してください。

## 必要パッケージのインストール

```bash
sudo apt update
sudo apt install openjdk-11-jdk-headless maven git
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
export PATH="$JAVA_HOME/bin:$PATH"
java -version
mvn -version
```

Ubuntu の [OpenJDK 11](https://packages.ubuntu.com/resolute/openjdk-11-jdk-headless) と [Maven](https://packages.ubuntu.com/resolute/maven)（いずれも universe）を使います。`java -version` と `mvn -version` の Java が両方とも `11` 系であることを確認し、以降も同じシェルで作業します。

## ソースコードのクローン

2025 年 4 月 3 日時点の最新版は `v0.6.102` です。

```bash
git clone https://github.com/NemProject/nem.git -b v0.6.102 nis1
```

## ビルド手順

```bash
cd nis1/infra
./package.build.sh build.log
./package.prepare.sh
```

## ネットワークの設定

ネットワークの指定がないため、メインネットかテストネットを設定します。
`mainnet` または `testnet` を入力してください。

```bash
sed -i 's/nem\.network = \r/nem.network = mainnet/g' package/nis/config.properties
```

## 任意の場所に配置

`nis1/infra/package` ディレクトリを任意の場所に移動します。
以降の配置・所有権・起動確認は[セットアップ記事](./setup.mdx#配置場所)に沿って進めてください。

**Testnet では `nem.network` の変更だけでは不十分です。** 起動前に、セットアップ記事の[Testnet 設定](./setup.mdx#testnet-config)にあるフォーク設定も必ず適用してください。[公式の Testnet 構成例](https://docs.nemtest.net/en/userbook/node/install/#configuration)を参照してください。
