NIS1 ノードに Servant を導入し、スーパーノードプログラムへ登録します。[NIS1 のセットアップ](./setup.mdx)を済ませ、参加条件や登録先は[公式のスーパーノードガイド](https://docs.nemtest.net/en/userbook/node/supernode-program/)で確認してください。

設定例の `YOUR_NODE_DOMAIN_OR_IP` はノードのドメイン名または IP アドレス、`YOUR_DELEGATED_PRIVATE_KEY` は委任用アカウントの秘密鍵に置き換えます。

## 必要パッケージと作業ユーザー

Ubuntu 26.04 LTS（amd64）で、セットアップ記事と同じ作業ユーザーを使います。Servant の設定ファイルの所有者とサービス実行ユーザーも、このユーザーにそろえます。

```bash
sudo apt update
sudo apt install curl jq unzip
```

Java 11 は[セットアップ記事](./setup.mdx#必要パッケージと作業ユーザー)で導入済みとします。サービスでも同じ Java 11 を指定します。

Servant の導入とプログラムへの登録に進む前に、[NIS1 の同期状況](./setup.mdx#synchronization)を確認してください。

## アカウントのデリゲート有効化

NEM ウォレットで「デリゲートアカウント管理」（サービス → デリゲートアカウント管理）を開きます。
リモートステータスが「無効」の場合は、「デリゲートアカウントの有効化/無効化」ボタンを押して有効化します（手数料 0.15 XEM）。
有効化には約 6 時間かかりますが、その間に他の作業を進めても問題ありません。

委任秘密鍵は、セットアップ記事の[委任秘密鍵を確認する](./setup.mdx#委任秘密鍵を確認する)に沿って取得してください。

## NIS1 クライアントの委任秘密鍵を確認する

セットアップ時に設定した `nis.bootKey` が、今回使う委任秘密鍵と一致することを確認します。

```bash
chmod 600 /opt/nis1/nis/config-user.properties
vi /opt/nis1/nis/config-user.properties
```

今回使う委任秘密鍵が設定済みなら、変更や再起動は不要です。

```ini title="/opt/nis1/nis/config-user.properties"
nis.bootKey = YOUR_DELEGATED_PRIVATE_KEY
```

未設定、または別の鍵が設定されている場合は、NIS1 クライアントを停止してから `nis.bootKey` を追加・変更します。既存の項目と重複させないでください。

```bash
sudo systemctl stop nis1
vi /opt/nis1/nis/config-user.properties
sudo systemctl start nis1
```

## Servant

### Servant をダウンロード

Servant の配布ファイルは、下記のリンクから確認できます。

[https://bob.nem.ninja/](https://bob.nem.ninja/)

以下は Servant `v0.0.4` の例です。

```bash
curl -OL https://bob.nem.ninja/servant_0_0_4.zip
```

ダウンロードしたファイルを展開します。

```bash
unzip servant_0_0_4.zip
rm servant_0_0_4.zip
```

`servant` ディレクトリを `nis1` と同じ場所（`/opt` など）に配置します。

```bash
sudo mv servant /opt
sudo chown -R "$(id -un):$(id -gn)" /opt/servant
cd /opt/servant
```

### Servant の設定

```bash
chmod 600 config.properties
vi config.properties
```

委任秘密鍵を保存するため、`config.properties` は実行ユーザーだけが読み書きできる `600` に制限します。

既存の `nem.host` と `servant.key` を次のように変更します。その他の設定は残してください。

```ini title="config.properties"
nem.host = YOUR_NODE_DOMAIN_OR_IP
servant.key = YOUR_DELEGATED_PRIVATE_KEY
```

## ポート開放

```bash
sudo ufw allow 7880
```

## サービス化（デーモン化）

### サービスファイルの作成

`YOUR_SERVICE_USER`・`YOUR_SERVICE_GROUP` は、作業ユーザーの `whoami`・`id -gn` で確認したユーザー名・グループ名に置き換えます。

```bash
sudo vi /etc/systemd/system/nis1-servant.service
```

```ini title="/etc/systemd/system/nis1-servant.service"
[Unit]
Description=NIS1 Servant
After=network.target

[Service]
ExecStart=/usr/lib/jvm/java-11-openjdk-amd64/bin/java -Xms256M -Xmx256M -XX:+UseG1GC -cp ".:jars/*" org.nem.rewards.servant.NodeRewardsServant
Restart=on-failure
RestartSec=2
User=YOUR_SERVICE_USER
Group=YOUR_SERVICE_GROUP
StandardOutput=journal
StandardError=journal
WorkingDirectory=/opt/servant
SuccessExitStatus=143

[Install]
WantedBy=multi-user.target
```

### サービスのリロード

```bash
sudo systemctl daemon-reload
```

### サービスの開始

```bash
sudo systemctl start nis1-servant
```

### サービスの停止

```bash
sudo systemctl stop nis1-servant
```

### サービスの有効化

```bash
sudo systemctl enable nis1-servant
```

## スーパーノードプログラムへの登録

[同期完了](./setup.mdx#synchronization)と NIS1・Servant の稼働を確認してから登録します。

### 初回登録

NEM ウォレットの「NEM スーパーノードプログラム」画面を開きます。
（サービス → NEM スーパーノードプログラム）

「プログラムへの参加」タブを押します。

- 参加アドレス: [cryptoBeliever_ の X アカウント](https://x.com/cryptoBeliever_)で毎月発表される enrollment address
- ノード主: 自分のノードのホスト名または IP アドレス

パスワードを入力し、「プログラムへの参加」ボタンを押します。

登録先はプログラム運営元の告知で確認してください。SNS の検索結果だけで送信先を決定しないでください。

### 毎月の再登録

参加を継続するには、**毎月の再登録が必要**です。翌月分の受付は当月末の 4 日前に始まります。毎月の告知で新しい参加アドレスと対象月を確認し、上記の登録操作を繰り返してください。前月のアドレスは使い回しません。[公式の再登録説明](https://docs.nemtest.net/en/userbook/node/supernode-program/#monthly-re-enrollment)を参照してください。

## 確認

次のコマンドで Servant が動作しているか確認します。

```bash
curl -s http://localhost:7880/nr/metaData | jq
```

次のサイトで自分のノードを検索し、ステータスがすべてグリーンなら正常です。
