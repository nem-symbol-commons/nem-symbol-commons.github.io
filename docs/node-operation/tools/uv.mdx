## 1. uv のインストール

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

完了後、再ログインまたは以下を実行してパスを反映します

```bash
source ~/.bashrc
```

確認

```bash
uv --version
```

## 2. uv を使用した Python 環境の作成

新しい仮想環境の作成方法

```bash
uv venv --python 3.12
```

仮想環境を現在のシェルで有効化

```bash
source .venv/bin/activate
```

環境を確認する

```bash
uv pip list --python .venv/bin/python
```

## 3. uv を使用したパッケージのインストール

```bash
uv pip install requests
```

- `.venv/` を自動で検出して、その環境にインストールします。
- `source .venv/bin/activate` しなくても OK です。

複数パッケージもまとめて

```bash
uv pip install numpy pandas matplotlib
```

インストール済みの確認

```bash
uv pip list
```
