鍵管理と、アプリケーションやノードを安全に扱うための情報を整理するカテゴリです。
秘密情報の取り扱い、署名前の確認、アクセス制御などを扱っていきます。

## サンプルや相談に含めない情報

秘密鍵、ニーモニック、API トークン、認証情報を、記事・コード例・ログ・Issue・PR に含めないでください。
公開鍵やアドレスを含むログでも、公開してよい情報か確認してから共有します。

ノードの具体的な設定は [ノード運用](../node-operation/index.md)、暗号技術の基礎は [共通技術・比較](../common/index.md) で扱います。
