TypeScript は **Node.js 24 以降**、Python は **3.10以降**を使います。
対象は `symbol-sdk@3.3.3` と `symbol-sdk-python==3.3.3` です。
SDK は鍵・トランザクション・署名を扱い、HTTP 通信と WebSocket 接続は別のライブラリで実装します。

## プロジェクトを作る

使用する言語のプロジェクトを作成し、コードを `src/` 以下に保存します。両方の言語を試す場合は、別々の作業ディレクトリを使います。

```text
src/
├── environment/
├── accounts/
├── transactions/
├── mosaic/
├── namespace/
├── metadata/
├── lock/
├── multisig/
├── observer/
├── restriction/
├── offline-signature/
└── verify/
```

Python のディレクトリ名は `offline_signature` とします。以下の実行コマンドは Linux / macOS / WSL を想定しています。

### TypeScript

```bash
mkdir symbol-typescript
cd symbol-typescript
npm init -y
npm pkg set type=module

# SDKと、HTTP・WebSocketのコード例に必要な依存関係をインストールする。
npm install --save-exact symbol-sdk@3.3.3 ws@8.18.3
npm install --save-dev --save-exact typescript@6.0.2 @types/node@24 @types/ws@8
mkdir -p src/environment
```

```json title="tsconfig.json"
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "rootDir": "src",
    "outDir": "dist",
    "strict": true,
    "skipLibCheck": true,
    "types": ["node"]
  },
  "include": ["src/**/*.ts"]
}
```

`npm list symbol-sdk` で3.3.3を確認します。次のファイルを保存し、SDK を読み込めることを確認します。
`SymbolFacade('testnet')` は Testnet 用の設定を選択します。この時点ではノードに接続しません。

```ts title="src/environment/check-sdk.ts"
import { SymbolFacade } from 'symbol-sdk/symbol';

// Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
const facade = new SymbolFacade('testnet');

console.log(facade.network.name, facade.network.identifier);
```

```bash
npx tsc
node dist/environment/check-sdk.js
```

### Python

```bash
mkdir symbol-python
cd symbol-python
python3 -m venv .venv
source .venv/bin/activate

# 仮想環境にSDKと通信ライブラリをインストールする。
python -m pip install symbol-sdk-python==3.3.3 requests==2.34.2 websockets==15.0.1
mkdir -p src/environment
```

`python -m pip show symbol-sdk-python` で3.3.3を確認します。
次のファイルを保存し、SDK を読み込めることを確認します。

```py title="src/environment/check_sdk.py"
from symbolchain.facade.SymbolFacade import SymbolFacade

# Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
facade = SymbolFacade('testnet')

print(facade.network.name, facade.network.identifier)
```

プロジェクトルートから、`src/` をモジュール検索パスに指定して実行します。

```bash
PYTHONPATH=src python src/environment/check_sdk.py
```

Windows の仮想環境は PowerShell で `.venv\Scripts\Activate.ps1` を実行して有効にします。
`PYTHONPATH` は `$env:PYTHONPATH="src"` と設定します。

両言語とも `testnet 152` と表示されれば準備完了です。[アカウント](accounts.mdx)で鍵とアドレスを生成します。
