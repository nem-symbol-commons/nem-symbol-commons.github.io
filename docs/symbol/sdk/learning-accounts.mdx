[環境構築](environment.mdx)のプロジェクトルートで、Testnet 専用のニーモニックを生成します。
秘密鍵とニーモニックはログに出さず、実資産のある Mainnet アカウントを使わないでください。

## ニーモニックを保存する

`.testnet-mnemonic` にニーモニックを保存します。既存ファイルがある場合は停止します。
TypeScript・Python は同じファイルを読み込めます。両方試す場合も生成は一度だけです。

<Tabs groupId="language">
<TabItem value="ts" label="TypeScript">

```ts title="src/accounts/prepare-accounts.ts"
// ニーモニックを新規ファイルに保存する。既存ファイルは上書きしない。
import { writeFileSync } from 'node:fs';
import { Bip32 } from 'symbol-sdk';

writeFileSync('.testnet-mnemonic', new Bip32().random(), { flag: 'wx', mode: 0o600 });
```

</TabItem>
<TabItem value="py" label="Python">

```py title="src/accounts/prepare_accounts.py"
# ニーモニックを新規ファイルに保存する。既存ファイルは上書きしない。
import os
from symbolchain.Bip32 import Bip32

fd = os.open('.testnet-mnemonic', os.O_WRONLY | os.O_CREAT | os.O_EXCL, 384)

with os.fdopen(fd, 'w', encoding='utf8') as file:
    file.write(Bip32().random())
```

</TabItem>
</Tabs>

次の内容を学習用プロジェクトの `.gitignore` に追加します。

```gitignore
.testnet-mnemonic
.venv/
node_modules/
dist/
```

このファイルは暗号化されていません。共有ストレージや Git に含めず、Testnet 専用のバックアップを保管します。

## アカウントを読み込む

同じニーモニックから Alice・Bob・Carol・Dave を順に導出します。両言語で同じアドレスになります。
以後のコードは `accounts/key-store.ts`／`accounts/key_store.py` からこれらのアカウントを読み込みます。
パスフレーズは空文字列です。同じアカウントを復元するには、同じニーモニックとパスフレーズを使います。

<Tabs groupId="language">
<TabItem value="ts" label="TypeScript">

```ts title="src/accounts/key-store.ts"
import { readFileSync } from 'node:fs';
import { Bip32 } from 'symbol-sdk';
import { SymbolFacade } from 'symbol-sdk/symbol';

// Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
export const facade = new SymbolFacade('testnet');

// 保存したニーモニックを使い、毎回同じアカウントを復元する。
const mnemonic = readFileSync('.testnet-mnemonic', 'utf8').trim();

const root = new Bip32().fromMnemonic(mnemonic, '');

// アカウントのインデックスに対応する導出パスから鍵を復元する。
function account(index: number) {
  const child = root.derivePath(facade.bip32Path(index));
  const pair = SymbolFacade.bip32NodeToKeyPair(child);
  return facade.createAccount(pair.privateKey);
}

export const [alice, bob, carol, dave] = [0, 1, 2, 3].map(account);
```

</TabItem>
<TabItem value="py" label="Python">

```py title="src/accounts/key_store.py"
from pathlib import Path
from symbolchain.Bip32 import Bip32
from symbolchain.facade.SymbolFacade import SymbolFacade

# Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
facade = SymbolFacade('testnet')

# 保存したニーモニックを使うと、同じアカウントを復元できる。
mnemonic = Path('.testnet-mnemonic').read_text(encoding='utf8').strip()

root = Bip32().from_mnemonic(mnemonic, '')


# インデックスに対応する導出パスからアカウントを復元する。
def account(index):
    child = root.derive_path(facade.bip32_path(index))
    pair = SymbolFacade.bip32_node_to_key_pair(child)
    return facade.create_account(pair.private_key)


alice, bob, carol, dave = (account(i) for i in range(4))
```

</TabItem>
</Tabs>

## Testnet の残高を用意する

[Faucet](https://testnet.symbol.tools/) に表示した **アドレス** を指定して Testnet XYM を受け取ります。
秘密鍵やニーモニックは入力しません。払い出し条件は利用時の案内を確認してください。
Alice は通常の送信、Bob はマルチシグの起案などで手数料を支払います。必要なアカウントに入金します。
新しいアカウントはオンチェーンの状態が作成されるまで `GET /accounts/{address}` が404になる場合があります。

マルチシグの章では Alice の権限構成を変更します。その章は別の作業ディレクトリと専用ニーモニックで試してください。
