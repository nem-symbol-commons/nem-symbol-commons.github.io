アカウントは、ブロックチェーン上で資産や権利を管理するための基本単位です。
Symbol では、アカウントは「秘密鍵」と「公開鍵」のペアで構成されています。

- 秘密鍵：アカウントの所有を証明する重要な情報です。他人に絶対に知られないようにしましょう。
- 公開鍵：秘密鍵から生成され、ネットワーク上でアカウントを識別するために使います。
- アドレス：公開鍵から作られる短い文字列で、送金や受け取りの際に利用します。

アカウントがあれば、Symbol ネットワークでトランザクションの送信や、モザイクの受け取りができます。

秘密鍵・ニーモニックのログ出力は移行時に削除しました。コード例中の `<自分のTestnet専用秘密鍵>` は説明用の伏せ字で、そのままでは実行できません。
既存鍵の例には、自分だけが管理する Testnet 用の値を手元で設定してください。生成した秘密情報はログや Git に残さず、保存方法の例は [クイックスタート](../quickstart.md) を参照してください。

## 3.1 アカウント作成

### 3.1.1 秘密鍵から生成

アカウントを作成する基本的な方法は、ランダムな秘密鍵を生成することです。
秘密鍵はアカウントの所有を証明する大切な情報で、ここから公開鍵とアドレスが作られます。
以下は、SDK を使って秘密鍵を生成し、新しいアカウントを作成する方法です。

<Tabs groupId="language">
  <TabItem value="ts" label="TypeScript">
    ```ts title="src/3_1_1_privatekey.ts"
    import { PrivateKey } from 'symbol-sdk';
    import { SymbolFacade } from 'symbol-sdk/symbol';

    // ランダムな秘密鍵生成
    const privateKey = PrivateKey.random();

    // 秘密鍵からアカウント生成
    const facade = new SymbolFacade('testnet');
    const account = facade.createAccount(privateKey);

    console.log('publicKey :', account.publicKey.toString());
    console.log('address   :', account.address.toString());
    ```

  </TabItem>
  <TabItem value="py" label="Python">
    ```py title="src/3_1_1_privatekey.py"
    from symbolchain.CryptoTypes import PrivateKey
    from symbolchain.facade.SymbolFacade import SymbolFacade

    # ランダムな秘密鍵生成
    privateKey = PrivateKey.random()

    # 秘密鍵からアカウント生成
    facade = SymbolFacade('testnet')
    account = facade.create_account(privateKey)

    print(f'publicKey : {account.public_key}')
    print(f'address   : {account.address}')
    ```

  </TabItem>
  <TabItem value="dart" label="Dart">
    ```dart title="src/c3_1_1_privatekey.dart"
    import 'package:symbol_sdk/facade/SymbolFacade.dart';
    import 'package:symbol_sdk/symbol/KeyPair.dart';
    import 'package:symbol_sdk/symbol/Network.dart';
    import 'package:symbol_sdk/CryptoTypes.dart';
    import 'package:symbol_sdk/utils/converter.dart';

    void main() {
      // ランダムな秘密鍵生成
      final privateKey = PrivateKey.random();

      // 秘密鍵からアカウント生成
      final facade = SymbolFacade(Network.TESTNET);
      final keyPair = KeyPair(privateKey);
      final address = facade.network.publicKeyToAddress(keyPair.publicKey);

      print('publicKey: ${keyPair.publicKey.toString()}');
      print('address: ${addressToString(address)}');
    }
    ```

  </TabItem>

### 3.1.3 ニーモニックから生成

もう一つの方法は、ニーモニック（単語の並び）からアカウントを作成することです。
ニーモニックがあれば、アカウントを失っても復元できます。
以下は、ニーモニックから秘密鍵・公開鍵・アドレスを生成してアカウントを作成する方法です。

<Tabs groupId="language">
  <TabItem value="ts" label="TypeScript">
    ```ts title="src/3_1_3_mnemonic.ts"
    import { Bip32 } from 'symbol-sdk';
    import { SymbolFacade } from 'symbol-sdk/symbol';

    // ニーモニック生成
    const bip32 = new Bip32();
    const mnemonic = bip32.random();

    // ニーモニックからアカウント生成
    const facade = new SymbolFacade('testnet');
    const password = '';
    const bip32Node = bip32.fromMnemonic(mnemonic, password);

    const maxAccounts = 3;
    for (let i = 0; i < maxAccounts; i++) {
      const bip32Path = facade.bip32Path(i);
      const childBip32Node = bip32Node.derivePath(bip32Path);
      const keypair = SymbolFacade.bip32NodeToKeyPair(childBip32Node);
      const account = facade.createAccount(keypair.privateKey);
      console.log(`publicKey : ${account.publicKey}`);
      console.log(`address   : ${account.address}`);
      console.log('===');
    }
    ```

  </TabItem>
  <TabItem value="py" label="Python">
    ```py title="src/3_1_3_mnemonic.py"
    from symbolchain.Bip32 import Bip32
    from symbolchain.facade.SymbolFacade import SymbolFacade

    # ニーモニック生成
    bip32 = Bip32()
    mnemonic = bip32.random()

    # ニーモニックからアカウント生成
    facade = SymbolFacade("testnet")
    password = ""
    bip32Node = bip32.from_mnemonic(mnemonic, password)

    max_accounts = 3
    for i in range(max_accounts):
        bip32_path = facade.bip32_path(i)
        child_bip32_node = bip32Node.derive_path(bip32_path)
        key_pair = SymbolFacade.bip32_node_to_key_pair(child_bip32_node)
        account = facade.create_account(key_pair.private_key)
        print(f"publicKey : {account.public_key}")
        print(f"address   : {account.address}")
        print('===')
    ```

  </TabItem>
  <TabItem value="dart" label="Dart">

## 3.2 公開アカウント

公開鍵だけが分かっている場合でも、公開鍵からアカウントを作成できます。
この方法は、相手のアカウントを扱いたいときや、受信専用のアカウント情報を作りたいときに便利です。
以下は、公開鍵からアカウントを作成し、アドレスを確認する方法です。

<Tabs groupId="language">
  <TabItem value="ts" label="TypeScript">
    ```ts title="src/3_2_publicAccount.ts"
    import { PublicKey } from 'symbol-sdk';
    import { SymbolFacade } from 'symbol-sdk/symbol';

    // 公開鍵
    const publicKey = new PublicKey(
      '43F7D852263AB7808C9234EEF496E944B5CF19FB91BE6F6881E1CEFDB0D664E9'
    );

    // 公開鍵から公開アカウント生成
    const facade = new SymbolFacade('testnet');
    const account = facade.createPublicAccount(publicKey);

    console.log('publicKey :', account.publicKey.toString());
    console.log('address   :', account.address.toString());
    ```

  </TabItem>
  <TabItem value="py" label="Python">

## 3.3 アドレス

アドレス文字列は、公開鍵や秘密鍵がなくてもオブジェクトとして扱えます。ただし、残高などの現在の状態を取得するには別途 REST API が必要です。
この方法は、相手のアドレスだけ知っている場合などに便利です。
以下は、アドレス文字列からアドレスオブジェクトを作成する方法です。

## 補足資料 2. ニーモニックのパスワード

ニーモニックから秘密鍵を生成するときに、パスワードを指定することができます。
パスワードを指定すると、ニーモニックだけでは秘密鍵を復元できなくなり、セキュリティが向上します。
パスワードは任意の文字列を指定できますが、忘れないように注意しましょう。
