アカウントは秘密鍵で署名し、公開鍵とアドレスで識別します。
秘密鍵から公開鍵、公開鍵からアドレスを計算できますが、アドレスから秘密鍵は復元できません。
[環境構築](environment.mdx)で用意したプロジェクトで実行します。

## 2.1 アカウントを生成する

暗号学的にランダムな秘密鍵から新しいアカウントを作ります。
秘密鍵は保存せず、公開鍵とアドレスを表示します。再実行すると別のアカウントになります。

<Tabs groupId="language">
<TabItem value="ts" label="TypeScript">

```ts title="src/accounts/create-account.ts"
import { PrivateKey } from 'symbol-sdk';
import { SymbolFacade } from 'symbol-sdk/symbol';

// Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
const facade = new SymbolFacade('testnet');

const account = facade.createAccount(PrivateKey.random());

console.log('publicKey:', account.publicKey.toString());

console.log('address:', account.address.toString());
```

</TabItem>
<TabItem value="py" label="Python">

```py title="src/accounts/create_account.py"
from symbolchain.CryptoTypes import PrivateKey
from symbolchain.facade.SymbolFacade import SymbolFacade

# Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
facade = SymbolFacade('testnet')

account = facade.create_account(PrivateKey.random())

print('publicKey:', account.public_key)

print('address:', account.address)
```

</TabItem>
</Tabs>

```bash
# TypeScript
npx tsc
node dist/accounts/create-account.js
# Python
PYTHONPATH=src python src/accounts/create_account.py
```

ネットワークへの登録要求は不要です。アドレスはローカルで生成できます。
入金などによって状態が作られるまでは、REST のアカウント検索が404になる場合があります。

## 2.2 既存の秘密鍵を読み込む

自分が管理する Testnet 専用の秘密鍵がある場合は、プロジェクトルートの `.testnet-private-key` から読み込みます。
ファイルには64桁の16進数だけを保存し、ファイル権限を制限して `.gitignore` に追加します。
秘密鍵をコード中の文字列やログに残しません。新規に学習する場合は次節のニーモニック方式を使ってください。

<Tabs groupId="language">
<TabItem value="ts" label="TypeScript">

```ts title="src/accounts/restore-account.ts"
import { readFileSync } from 'node:fs';
import { PrivateKey } from 'symbol-sdk';
import { SymbolFacade } from 'symbol-sdk/symbol';

// Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
const facade = new SymbolFacade('testnet');

// 保存済みの Testnet 専用秘密鍵を読み込む。
const privateKey = new PrivateKey(readFileSync('.testnet-private-key', 'utf8').trim());

const account = facade.createAccount(privateKey);

console.log(account.address.toString());
```

</TabItem>
<TabItem value="py" label="Python">

```py title="src/accounts/restore_account.py"
from pathlib import Path
from symbolchain.CryptoTypes import PrivateKey
from symbolchain.facade.SymbolFacade import SymbolFacade

# Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
facade = SymbolFacade('testnet')

# 秘密鍵を使ってアカウントを復元する。ログには出力しない。
private_key = PrivateKey(
    Path('.testnet-private-key').read_text(encoding='utf8').strip()
)

account = facade.create_account(private_key)

print(account.address)
```

</TabItem>
</Tabs>

秘密鍵ファイルも暗号化されていません。実資産を持つ Mainnet アカウントを入力しないでください。

## 2.3 ニーモニックから派生させる

ニーモニックから複数の鍵を導出します。SDK の `bip32Path`／`bip32_path` でネットワークに対応する導出パスを選びます。
実行するたびに新しいニーモニックを生成します。同じアカウントを使い続けるには、[学習用アカウントの準備](learning-accounts.mdx)でニーモニックを保存してください。

<Tabs groupId="language">
<TabItem value="ts" label="TypeScript">

```ts title="src/accounts/derive-accounts.ts"
import { Bip32 } from 'symbol-sdk';
import { SymbolFacade } from 'symbol-sdk/symbol';

// Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
const facade = new SymbolFacade('testnet');

const bip32 = new Bip32();

// 複数のアカウントを導出するためのニーモニックを生成する。
const mnemonic = bip32.random();

const root = bip32.fromMnemonic(mnemonic, '');

for (let index = 0; index < 3; index++) {
  const child = root.derivePath(facade.bip32Path(index));
  const pair = SymbolFacade.bip32NodeToKeyPair(child);
  console.log(index, facade.createAccount(pair.privateKey).address.toString());
}
```

</TabItem>
<TabItem value="py" label="Python">

```py title="src/accounts/derive_accounts.py"
from symbolchain.Bip32 import Bip32
from symbolchain.facade.SymbolFacade import SymbolFacade

# Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
facade = SymbolFacade('testnet')

bip32 = Bip32()

# 保存したニーモニックを使うと、同じアカウントを復元できる。
mnemonic = bip32.random()

root = bip32.from_mnemonic(mnemonic, '')

for index in range(3):
    child = root.derive_path(facade.bip32_path(index))
    pair = SymbolFacade.bip32_node_to_key_pair(child)
    print(index, facade.create_account(pair.private_key).address)
```

</TabItem>
</Tabs>

同じニーモニックでも、パスフレーズ・導出パス・インデックスが異なると別の鍵になります。
パスフレーズを設定した場合は、復元にもその値が必要です。
`Bip32` の既定の単語リストは英語です。`Bip32('ed25519', 'japanese')` を指定すると日本語に変わります。
ウォレットに読み込む場合は単語リストと導出パスの対応を確認してください。

## 2.4 公開鍵とアドレスを扱う

公開アカウントは署名用の秘密鍵を持ちません。相手の公開鍵からアドレスを計算したり、受信者アドレスを検査したりするときに使います。
次の公開鍵は例示用で、宛先への送金には使いません。

<Tabs groupId="language">
<TabItem value="ts" label="TypeScript">

```ts title="src/accounts/public-account.ts"
import { PublicKey } from 'symbol-sdk';
import { Address, SymbolFacade } from 'symbol-sdk/symbol';

// Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
const facade = new SymbolFacade('testnet');

const account = facade.createPublicAccount(
  new PublicKey('43F7D852263AB7808C9234EEF496E944B5CF19FB91BE6F6881E1CEFDB0D664E9'),
);

const address = new Address(account.address.toString());

console.log(address.toString());

console.log(
  'valid Testnet address:',
  facade.network.isValidAddressString(address.toString()),
);
```

</TabItem>
<TabItem value="py" label="Python">

```py title="src/accounts/public_account.py"
from symbolchain.CryptoTypes import PublicKey
from symbolchain.facade.SymbolFacade import SymbolFacade
from symbolchain.symbol.Network import Address

# Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
facade = SymbolFacade('testnet')

account = facade.create_public_account(
    PublicKey('43F7D852263AB7808C9234EEF496E944B5CF19FB91BE6F6881E1CEFDB0D664E9')
)

address = Address(str(account.address))

print(address)

print('valid Testnet address:', facade.network.is_valid_address_string(str(address)))
```

</TabItem>
</Tabs>

アドレスの形式が正しくても、残高があることや相手がその秘密鍵を持つことは証明しません。

## 2.5 残高を確認する

[学習用アカウントの準備](learning-accounts.mdx)でアカウントを作り、Faucet から Alice に入金します。
`SYMBOL_NODE` に Testnet ノードの HTTPS REST URL を設定します。

```bash
export SYMBOL_NODE='https://401-sai-dual.symboltest.net:3001'
```

接続先が使えない場合は [Testnet ノード一覧](https://symbolnodes.org/nodes_testnet/)から選び直してください。
ノードのネットワーク識別子・generation hash seed・epoch を SDK の Testnet 設定と照合してから、残高を取得します。

<Tabs groupId="language">
<TabItem value="ts" label="TypeScript">

```ts title="src/accounts/account-info.ts"
import { SymbolFacade } from 'symbol-sdk/symbol';
import { alice } from './key-store.js';

// Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
const facade = new SymbolFacade('testnet');

const node = process.env.SYMBOL_NODE?.replace(/\/$/, '');

// HTTPエラーを検出し、応答待ちを15秒に制限する。
async function request(path: string, method = 'GET', body?: string) {
  if (!node) throw new Error('SYMBOL_NODE に Testnet の REST URL を設定してください');
  const response = await fetch(`${node}${path}`, {
    method,
    body,
    headers: { 'Content-Type': 'application/json' },
    signal: AbortSignal.timeout(15000),
  });
  if (!response.ok) throw new Error(`${method} ${path}: HTTP ${response.status}`);
  return response.json();
}

// SDK とノードのネットワーク設定が一致することを確認する。
async function checkNetwork() {
  const info = await request('/node/info');
  const properties = await request('/network/properties');
  const seed = facade.network.generationHashSeed.toString();
  const epoch = facade.network.datetimeConverter.epoch.getTime() / 1000;
  if (
    info.networkIdentifier !== facade.network.identifier ||
    info.networkGenerationHashSeed !== seed ||
    properties.network.generationHashSeed !== seed ||
    properties.network.epochAdjustment !== `${epoch}s`
  ) {
    throw new Error('SDK と接続先の Testnet 設定が一致しません');
  }
}

await checkNetwork();

console.log(await request(`/accounts/${alice.address}`));
```

</TabItem>
<TabItem value="py" label="Python">

```py title="src/accounts/account_info.py"
import os
import requests
from symbolchain.facade.SymbolFacade import SymbolFacade
from accounts.key_store import alice

# Testnet のアドレス生成・時刻・署名に使う設定を選ぶ。
facade = SymbolFacade('testnet')


# HTTPエラーを検出し、応答待ちを15秒に制限する。
def request(path, method='GET', body=None):
    node = os.environ['SYMBOL_NODE'].rstrip('/')
    response = requests.request(
        method,
        node + path,
        data=body,
        headers={'Content-Type': 'application/json'},
        timeout=15,
    )
    response.raise_for_status()
    return response.json()


# SDK とノードのネットワーク設定が一致することを確認する。
def check_network():
    info = request('/node/info')
    properties = request('/network/properties')
    seed = str(facade.network.generation_hash_seed)
    epoch = int(facade.network.datetime_converter.epoch.timestamp())
    if (
        info['networkIdentifier'] != facade.network.identifier
        or info['networkGenerationHashSeed'] != seed
        or properties['network']['generationHashSeed'] != seed
        or (properties['network']['epochAdjustment'] != f'{epoch}s')
    ):
        raise ValueError('SDK と接続先の Testnet 設定が一致しません')


check_network()

print(request(f'/accounts/{alice.address}'))
```

</TabItem>
</Tabs>

`account.mosaics` の `id` は16進数、`amount` は最小単位を表す10進数の文字列です。
XYM の可分性は6なので、`1000000` が1 XYMです。他のモザイクではそのモザイクの可分性を使います。
