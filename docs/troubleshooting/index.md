エラーメッセージや症状から、原因の切り分けと対処方法を探すためのカテゴリです。
具体的な事例を、再現条件・調査方法・対処・確認方法の順に整理していきます。

## 調査前に整理する情報

- 対象チェーンとネットワーク。
- OS、実行環境、関連ソフトウェアのバージョン。
- 実行した操作、期待した結果、実際の結果。
- 再現条件と、秘密情報を取り除いたエラーメッセージやログ。

記事にない問題や記述の不備は、[Issue](https://github.com/nem-symbol-commons/nem-symbol-commons.github.io/issues) で共有できます。
秘密情報の扱いは [セキュリティ](../security/index.md)、ノードの構築・保守は [ノード運用](../node-operation/index.md) を参照してください。
